# NeverDown — Arkiv friction notes

During C5 we learned that Arkiv writes are wallet-owned, expire, and are stronger when queries filter by indexed attributes. Seed/query behavior is deterministic but requires careful identity and expiry handling.

Future Arkiv improvements we would value:
- clearer SDK install/type setup
- simpler schema authoring for typed app fields
- better ergonomic filters for ownership/exiry in early debugging
